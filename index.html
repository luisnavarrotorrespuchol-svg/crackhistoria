Cómo se juega

  1. Cada día hay un personaje histórico misterioso de cualquier época y lugar del mundo.
  2. Se revela una pista para empezar. Es la más difícil.
  3. Cada vez que falles, se revela una nueva pista, algo más fácil.
  4. Tienes un máximo de 5 pistas y 5 intentos para acertar.

Cuantas menos pistas necesites, más puntos consigues: 100, 80, 60, 40 o 20. El personaje es el mismo para todo el mundo cada día.
